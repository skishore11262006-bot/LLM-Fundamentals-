# 🧠 LLM Fundamentals Playground

A hands-on Python project for learning and experimenting with the fundamental concepts behind Large Language Models (LLMs).

This project uses **Python, Ollama, and Qwen 2.5** to demonstrate how prompting and generation work in practical applications.

---

## 🚀 What I Learned

This project covers the following LLM fundamentals:

- 🔤 Tokenization
- 🧠 Context Window
- 🔄 Next-Token Prediction
- 📝 System Prompts
- 👤 Role Prompting
- 🎯 Zero-Shot Prompting
- 📚 Few-Shot Prompting
- 🌡️ Temperature
- 🔗 Chain-of-Thought concepts
- 🤖 Local LLM inference using Ollama

---

## 🛠️ Technologies Used

- Python
- Ollama
- Qwen 2.5 0.5B
- Hugging Face Transformers
